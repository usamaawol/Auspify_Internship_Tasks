## About the Internship

This repository contains six frontend development projects completed as part of the **Auspify Technologies Frontend Development Internship**.

The internship provided an opportunity to strengthen practical frontend development skills by designing and implementing web applications, working with modern development technologies, building reusable components, and developing functional user interfaces.

Throughout the internship, I worked on different types of projects, ranging from responsive landing pages and personal portfolios to interactive applications, e-commerce interfaces, and advanced administrative dashboards.

The primary objective was to apply theoretical knowledge to practical development tasks while improving problem-solving abilities, UI/UX design understanding, code organization, and frontend development practices.

This repository documents the six selected internship projects, their objectives, major functionalities, and technologies.

## Projects Overview

This internship repository contains six independent projects.

### Task 1 — RedFox Tech: Responsive Landing Page

**Project Type:** Business Landing Page

**Overview:**

RedFox Tech is a responsive business landing page developed to demonstrate modern website design and frontend development fundamentals.

The project focuses on creating a professional online presence for a technology-oriented business through a structured layout, clear navigation, and organized content sections.

The interface is designed to communicate business information and present services in an accessible and visually consistent way.

**Key Areas:**
- Responsive website layout.
- Navigation bar and structured page sections.
- Business introduction and service presentation.
- About and contact sections.
- Consistent visual styling.
- User-friendly navigation.
- Responsive behavior across different screen sizes.

**Learning Outcomes:**
- HTML document structure.
- CSS styling and layout techniques.
- Responsive web design.
- Navigation and section organization.
- UI/UX design fundamentals.

**Project Folder:** `Task1/`

## Running the Projects Locally

Each project is maintained independently, so the installation and execution procedures may differ.

For projects using Node.js and npm:

```bash
cd Task6
npm install
npm run dev
```

Open the local URL displayed in your terminal.

For projects using plain HTML, CSS, and JavaScript, open the `index.html` file in a browser or use a local development server.

**Important:** Check the individual README files for the correct commands and requirements of each project.
